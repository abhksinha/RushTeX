# Architecture and status

These three documents are the project's guidance, mirrored from the maintainers' working journal:

- `progress.md`: what is done and what is next, and the gate every change must pass.
- `native-architecture.md`: the long-term rules (exactness, data, memory, hot loops, storage).
- `guarded-direct-lowering.md`: how every native feature is built (Guarded Direct Lowering, GDL).

They cite dated decision notes (`2026-10-…-*.md`) that are not published; the rules themselves are complete here.
