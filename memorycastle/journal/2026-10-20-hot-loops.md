# Hot loops after the parity work
Author: abhi+claude | Date: 2026-10-20
Files: `src/math/math_parser.rs`, `src/expand/expand_mod.rs`, `examples/bench_loop.rs`, `src/backend/backend_deflate.rs`, `src/layout/layout_linebreak.rs`

## Context
After testmath reached 99.6%, the user asked for hot loops to be found and removed. Profiles used macOS `sample` on `examples/bench_loop.rs`, a new in-process `compile_str` loop that prints the median and minimum time.

## Decision
- `parse_expression_inner` reads the lead byte once per token. The structural probes (`&`, `\\`, `\cr`, `\right`, `\eqno`, `\tag`, `\label`, `\notag`, infix fractions) now run only when that byte is `\` or `&`. Before, each token paid about 15 `starts_with` memcmps.
- `ends_with_hskip` checks only the last control sequence of the output for `\hspace{`, instead of an `rfind` over the whole expanded output.
- `number_rows` scans each row's `\begin{` occurrences once, instead of a `format!` plus `find` for each of the 8 alignment names.
- `env_stack` starts with a capacity of 16.

## Rejected
- A faster DEFLATE (21% self time on the stress document). It is already a single-probe fixed-Huffman encoder at about 470 MB/s, and the earlier note's reasoning holds.
- Tuning `run_pass`/`try_break` further (15% self). This is the Knuth–Plass core, and earlier branch-trimming experiments were slower.
- Caching math layout between `measure_display` and the render pass. The cost is spread across `layout_node` per node (prologue, `font_params`), and there is no single loop to remove.

## Measured
- testmath, in-process median: 4.57 ms before, 4.37 ms after. Parity is unchanged (99.6%).
- Stress document (`scripts/generate_100k_doc.py`): 29.5 ms against 25.3 ms at HEAD. This is not a code regression. HEAD set the document in Times by mistake; it now uses Computer Modern as pdfLaTeX does, with kerns and ligatures, which makes the content streams 29% larger (2.20 to 2.84 MB). DEFLATE and stream writing grow with that.
- Display/label scaling test (500/1000/2000 blocks): 3.6/6.6/13.1 ms, linear.

## Open
- DEFLATE is now the largest single cost on text-heavy documents. `--threads` already overlaps it with layout.
