# Form XObjects (`\pdfxform`, `\pdfrefxform`, `\pdflastxform`)
Author: abhi+claude | Date: 2026-10-22
Files: `src/engine/engine_xform.rs`, `scripts/parity/corpus/array.tex`, `scripts/parity/corpus/footmisc.tex`, `src/engine/engine_ship.rs`, `src/engine/engine_color.rs`, `src/engine/engine_whatsit.rs`, `src/engine/engine_pack.rs`, `src/engine/engine_page.rs`, `src/engine/engine_linebreak.rs`, `src/engine/engine_microtype.rs`, `src/engine/engine_showbox.rs`, `src/engine/engine_run.rs`, `src/engine/engine_native.rs`, `src/engine/engine_pdfdoc.rs`, `src/engine/engine_mod.rs`, `src/backend/backend_ship.rs`, `src/backend/backend_pdftex.rs`

## Context
fancyhdr.dtx (after PDF inclusion) stopped at `\pdfxform`: pgf ships shadings as forms
(`pgfsys-pdftex.def`, `\immediate\pdfxform resources{/Shading ...}`).

## Decision
- New `engine_xform.rs`. `\pdfxform` keeps the box's record index (the node store is
  append-only, so a later ship finds it), size, `attr` and `resources`; clears the register.
- Shipped as pdfTeX does: `\immediate` at once, else at the end of the first page that
  shows it, then the forms it shows (`Write out pending forms`). `ship_page` was split into
  `walk_box` (one walk for pages and forms), `ship_forms`, `ship_form`.
- Colour stacks get a form side (utils.c `form_current`/`form_stack`, initialised to the
  stack's literal, never reset); `ColorStacks::swap_form` swaps it in for the form walk, so
  the page side is untouched. No page-start literals in a form.
- `out_form`: `q 1 0 0 1 x y cm /Fm<k> Do Q` with y at baseline+depth (`TextState::form_ref`).
  XObject resources list forms first, then images, as pdfTeX's.
- Form object: pdfTeX's header (`/Type /XObject /Subtype /Form`, attr, `/BBox`, `/FormType 1`,
  `/Matrix`) with the resources inline (shared font dict + `resources` text + XObjects).
- `XFORM` whatsit sized like `XIMAGE`: one `whatsit::sized` test in pack, page builder, line
  breaker, protrusion and `\showbox` (`\pdfrefxform(h+d)xw`).

## Rejected
- New `Prim` variants: the `Prim` enum is full (256, `repr(u8)`, stored in the format as a
  byte). The two commands go through the long-tail `Meaning::Native` path by name, like
  `micro_command`; widening `Prim` would change the format for two commands.
- Rendering every form at `\pdfxform` time: wrong for colour stacks (pdfTeX's state at ship).
